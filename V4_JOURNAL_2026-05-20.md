### 5. Bug fix — `bot_v2/concepts/setup_quality.py`

**Avant** : `multi_liquidity_sweep` tolerance 0.001 = `0.1% du prix`
→ Sur XAUUSD à 2000$ = 2$ tolerance, **toujours True**

**Après** :
```python
tol_price = max(atr_at_sweep * 0.3, swing.price * 0.0005)
same_side_swings = [
    s for s in swings
    if s.kind == swing.kind
    and s.index != swing.index  # exclut le swing lui-même
    and abs(s.price - swing.price) <= tol_price
]
```
